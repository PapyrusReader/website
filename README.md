# Papyrus website

Landing page for the [Papyrus](https://github.com/Eoic/Papyrus) project - a free, open-source e-book reader and library manager for Android, iOS, Windows, macOS, Linux, and Web.

## Getting Started

```bash
npm install
npm run dev
```

This starts a local server at `http://localhost:8090` with live SCSS recompilation.
